# Project 0 - Loan management system

## Description
A user can register, login, create, update and delete a loan.

## Technologies
- Java 17
- PostgreSQL
- JDBC
- Log4j
- JUnit
- Javalin

## Functionality
- Register user
- Login
- Create loan
- Create user
- Update loan
- Delete loan
- Get loan

## Installation
1. Database setup example:
   db.url=jdbc:postgresql://localhost:5432/myDatabase
   db.username=postgres
   db.password=12345

## Usage
1. Run application and Postman
2. Login or register
3. Select endpoint to perform operations
